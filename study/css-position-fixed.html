CSS position: fixed 와 레이아웃 시프트

fixed 요소가 fullscreen 카드로 확장될 때, 원래 자리의 레이아웃이 갑자기 무너지지 않도록 빈 자리를 얼마나 보존할지 고민했다. transform 대신 inset 을 애니메이션하니 훨씬 자연스러웠다.

hover 시 걸어둔 transform 이 fullscreen 상태에서도 함께 적용되면서 박스가 화면 밖으로 튀어나가 잘려 보이는 문제가 있었다 — :not(.is-fullscreen) 으로 범위를 명확히 나눠서 해결했다.

이 사이트의 각 페이지에 있는 카드 클릭 → 전체화면 인터랙션도 같은 원리로 만들었다.
