이 페이지는 GitHub 저장소에 직접 파일을 커밋하는 관리자 도구입니다.
아래 입력한 GitHub 토큰은 이 브라우저에서 GitHub API로만 바로 전송되고, 어디에도 저장되지 않습니다 (단, "이 브라우저에 토큰 기억하기"를 체크하면 이 브라우저의 localStorage에만 저장됩니다). 이 페이지 주소나 화면을 다른 사람과 공유하지 마세요.

1. GitHub 연결 토큰이 있어야 게시할 수 있어요. 미리보기/복사만 할 거면 건너뛰어도 됩니다.

토큰은 어떻게 만드나요?
  1. github.com에 로그인한 상태로 Settings → Developer settings → Personal access tokens → Fine-grained tokens → "Generate new token" 으로 이동합니다.
  2. Repository access를 "Only select repositories" 로 설정하고 miku-tenshi.github.io 저장소만 선택합니다.
  3. Permissions → Repository permissions 에서 Contents: Read and write 로 설정합니다.
  4. 만료 기간을 정하고 토큰을 생성한 뒤, 표시되는 토큰 값을 복사해 위 칸에 붙여넣습니다. (토큰은 생성 직후 한 번만 보여줍니다.)
