토큰은 어떻게 만드나요?
  1. github.com 로그인 상태에서 Settings → Developer settings → Personal access tokens → Fine-grained tokens → "Generate new token" 으로 이동합니다.
  2. Repository access를 "Only select repositories" 로 설정하고 miku-tenshi.github.io 저장소만 선택합니다.
  3. Permissions → Repository permissions에서 Contents: Read and write 로 설정합니다.
  4. 만료 기간을 정하고 생성한 뒤, 표시되는 토큰 값을 복사해 위 칸에 붙여넣습니다 (한 번만 보여줘요).
